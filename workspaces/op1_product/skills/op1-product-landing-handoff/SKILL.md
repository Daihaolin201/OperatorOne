# Landing Handoff Builder

1. Read `research/stage3_project_blueprint.json`.
2. Extract:
   - ICP
   - core problem
   - MVP scope
   - value proposition
   - constraints
   - primary CTA
3. Write final handoff to `../../handoffs/product_to_marketing.json`.
4. Keep language outcome-focused and concrete.

## Quality bar
- Handoff must be executable by marketing without back-and-forth clarification.
- Every claim in positioning should be traceable to stage-1/2 evidence.
- Do not invent features outside MVP scope.
