# MVP Scope Builder

1. Take one `advance` opportunity from stage-2 decision log.
2. Build a 14-day test blueprint using `../../../framework/templates/stage3_project_blueprint.template.json`.
3. Define strict boundaries:
   - in scope
   - out of scope
4. Define a concrete paid-validation experiment:
   - channel
   - sample target
   - offer
5. Define success metric and kill criteria before execution.
6. Write output to `research/stage3_project_blueprint.json`.

## Quality bar
- Scope must be buildable by a small team in <=14 days.
- Success metric must be measurable and binary enough for decision-making.
- Kill criteria must be explicit, not “if results are bad”.
