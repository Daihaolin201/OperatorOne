# 这个 Agent 的 Product 能力定义（优化版）

## 你问的核心：是否要让智能体具备 Product 设计能力？
是的，而且不是“灵感型能力”，而是**决策型能力**：
1. 能发现机会；
2. 能筛选并解释为什么；
3. 能把决策产物结构化，驱动后续团队执行。

## 能力拆分（必须具备）
1. **Evidence Gathering（证据收集）**
   - 不凭空判断，只接受可追溯信号。
2. **Screening Logic（筛选逻辑）**
   - 有权重、有门槛、有拒绝理由。
3. **Project Framing（立项定义）**
   - 形成可测试的 MVP 边界和实验计划。
4. **Downstream Compatibility（下游可消费）**
   - 输出结构化文件，营销/运营可直接接手。

## 关键优化点
- 从“给结论”升级为“给结论 + 依据 + 风险 + 下一步动作”。
- 从“文档输出”升级为“stage-gate 数据流输出”。
- 从“单项目导向”升级为“框架先行、项目后选”。

## 验收标准（客户开箱即用）
- 客户只需给目标市场范围，agent 即可跑完整 Stage 1-3。
- 每一步都产出模板化文件，不依赖口头解释。
- 客户能直接看到：为什么选 A 不选 B、失败就停在哪里。
