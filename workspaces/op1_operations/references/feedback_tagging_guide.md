# Feedback Tagging Guide (Stage2)

## Purpose
Ensure consistent topic/subtopic tagging for Process feedback capability.

## Top-level topics
- pricing
- trust
- integration
- onboarding
- performance
- support
- billing
- retention
- general

## Practical rules
1. Prefer taxonomy topics over ad-hoc labels.
2. Use `pricing` for budget/cost/ROI objections.
3. Use `trust` for unsubscribe/security/fraud concerns.
4. Use `retention` for not-now / competitor-lock-in timing signals.
5. Use `onboarding` for manual work, setup friction, reporting friction.
6. Use `billing` for invoice/payment/chargeback operations.
7. Use `performance` for bug/error/latency/stability feedback.
8. If uncertain after rules, assign `general/uncategorized` and review in triage.

## Quality requirement
- Unknown topic rate should remain below configured threshold (`max_unknown_topic_rate`).
